# 敵対的検証（出力確定前に必須）

報告文のドラフトを作成したら、最終報告として出力する前に、
必ずサブエージェント `report-verifier` を呼び出して検証を依頼する。

- `REPORT_DRAFT`: 作成した報告文ドラフトの全文
- `CONTEXT`:
  - 呼び出し元エージェント名: このエージェント自身の frontmatter `name` の値
  - `REPO_ROOT`: リポジトリパスの特定を行うエージェントの場合、確定したパス
    （行わないエージェントの場合はこの項目を省略し、代わりに調査対象を特定する
    情報を記載する）
  - 出力フォーマット規約: このエージェントの「## 出力フォーマット」セクションの内容
  - （該当する場合）補足: 秘密情報を含みうるファイル（このエージェントの厳守事項に
    列挙されているもの）については、report-verifier がファイル照合を行う際も
    全文読み出しはしないよう申し添える

検証結果に応じて次のように扱う:

| 検証結果 | 対応 |
|---|---|
| `VERIFICATION_OK` | そのまま最終報告として出力する |
| `VERIFICATION_ISSUES`（軽微・情報のみ） | 指摘を踏まえてドラフトを修正し、再検証はせず最終報告として出力する |
| `VERIFICATION_ISSUES`（重大を含む） | 指摘を踏まえてドラフトを修正し、`report-verifier` を1回だけ再度呼び出す。再検証でも重大な指摘が残る場合は、その指摘内容を報告の末尾に「検証で未解消の懸念」として明記した上で出力する（それ以上の再検証は行わない） |

## 厳守事項（このスキルの範囲）

- **`report-verifier` の呼び出しは1件の報告ドラフトにつき最大2回まで**とする（無限ループ防止）。
- `report-verifier` を呼び出す際は、呼び出し先にこのエージェント自身を再度呼び出させないこと（無限ループ防止）。
